# Field Shift — data coverage (what is published today)

This page lists the processed data that anyone can download right now from the GitHub Releases of this
repository, for the NASA Space Apps Challenge 2026 submission (**"Field Shift: Adapting Farms with NASA
Data"**). It is linked from `docs/demo/project_page.md`.

How to read it:

- **Only published data counts.** A release is listed as *published* only if its zips are public on the
  Releases page. Releases that are still being built (Kansas; Missouri, Wisconsin and South Dakota; the first
  batch Iowa, Illinois and Indiana; the field-level release) are listed as **in progress, with no numbers**.
- **Numbers are counted, not typed.** The section between the two markers below is written by
  `docs/demo/coverage.py`. The script lists the releases through the public GitHub API, downloads each zip into
  `data/` (outside git), checks its `.sha256`, and counts rows, columns, counties and years inside every
  processed CSV. To refresh the page after a new release:
  `.venv/bin/python -X utf8 docs/demo/coverage.py`.
- **One release per group of states** (`datos-<states>`, made by `scripts/entregar.py`), one zip per package.
  Each zip holds the package CSVs, its data card (`docs/datasets/<package>.md`), the county list
  (`data/reference/condados.csv`), the year windows (`anios.csv`) and the download manifest.
- **Keys and format** are the same in every file: 5-digit county FIPS (`fips`) or 2-digit state FIPS
  (`fips_estado`, for data that only exist by state), then `anio` (harvest year), `mes` (`YYYY-MM`) or `fecha`
  (`YYYY-MM-DD`). Missing values are empty cells, never 0 or -999 (`CLAUDE.md` §4).

Notes on the counts:

- "Counties" counts distinct 5-digit FIPS in the county-level CSVs of the release. "Units" is the number of
  distinct counties (`fips`) or states (`fips_estado`) in each file.
- "Years (county files)" is the span of `anio` over the county-level files. Not every file covers the whole
  span: SMAP soil moisture (`agua_diario`, `agua_mensual`) starts in 2015 because SMAP launched that year,
  GRACE-DA-DM (`agua_semanal`) starts in 2003, crop rotations from the Cropland Data Layer start in 2008 (the
  first year with national coverage), the Census of Agriculture has only 2012, 2017 and 2022, and Annual NLCD
  (`paisaje`) ends in 2024. Details and missing-value rates are in each package's data card inside the zip.
- `produccion_anual.csv` (USDA NASS county yields) can have fewer counties than the release: NASS does not
  publish every county, and the "other (combined) counties" rows are left out (`docs/datasets/cultivos.md`).
- The per-state files (`fenologia_estado`, `economia_*`) come from state-level USDA sources (Crop Progress,
  prices and costs).
